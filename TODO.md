## 2. Visualization tool (`src/visualization/`)

A standalone node or module that records and renders the full agentic decision-making
process — what the controller decided, when, and what the physical system did in response.
Outputs a video that can be inspected post-run without re-running the simulation.

**Two frame types, composed into one video per trial:**

- [ ] **Physics frames** — captured inside `discreteBeam` / `discreteRod` at each timestep:
  - Beam/rod shape (nodes + connections)
  - Wall line (beam) or reference plane (rod)
  - Timestep and cumulative time in title
- [ ] **Decision frames** — generated by programmer node after each orchestrator cycle:
  - Current shape + overlay of target BC as an arrow/arc annotation
  - Iteration number, BC values `(x₀, y₀, θ)` or 3D equivalent
  - Shape error % from `compute_shape_error`
  - LLM convergence reasoning (one-line quote)
- [ ] **Video composition**: interleave physics frames (normal speed) + decision frames (held 2-3 s); one `.mp4` per trial
- [ ] **Config flags** (add to `config.py` Section 2):
  - `SAVE_VIDEO` — enable/disable
  - `VIDEO_FPS` — set to `None` for auto (floor = `1/DT`)
  - `VIDEO_DPI`
- [ ] **File layout**:
  ```
  VISUALIZATION_DIR/
    trial_DATETIME_TARGET_MODE/
      trial.mp4
      metadata.json   (target, mode, iterations, final error)
  ```
- [ ] Works for both beam (2D plot) and rod (3D plot or projected 2D)
